# HR Management Application

Application de gestion des ressources humaines améliorée dans le cadre d’un stage professionnel.

## Modules existants

* Gestion des employés
* Gestion des congés
* Gestion des salaires
* Gestion des absences

## Travail réalisé

Développement et intégration du module disciplinaire avec :

* Gestion des avertissements
* Gestion des contentieux

## Technologies utilisées

* Laravel
* Laravel Sanctum
* React.js
* Vite
* MySQL

## Auteur

Projet réalisé dans le cadre d’un stage.
